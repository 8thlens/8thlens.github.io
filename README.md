# 8th.lens Portfolio

A static portfolio site for Lucian Corduneanu.

## Before publishing
1. Replace `YOUR-EMAIL-HERE` in `index.html`.
2. Replace the `#` social links with your real URLs.
3. Replace placeholder project blocks with your videos/images when ready.

## GitHub Pages
Upload these files to a GitHub repository and enable Pages from Settings → Pages → Deploy from a branch → main → / (root).
